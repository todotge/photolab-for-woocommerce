# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in Photolab, please report it privately to the maintainers. **Do not open a public issue.**

Email: security@todot.it

Please include:
- Description of the vulnerability
- Steps to reproduce
- Affected versions
- Any potential mitigations

We aim to respond within 48 hours and will keep you updated on the resolution timeline.

## Supported Versions

| Version | Supported |
|---------|-----------|
| 0.0.x   | ✅ Active development |

## Disclosure Policy

Once a fix is released, we will publish a security advisory crediting the reporter (unless anonymity is requested).
